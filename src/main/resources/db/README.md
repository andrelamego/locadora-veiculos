# Banco de dados

Scripts SQL Server para a locadora de veiculos, seguindo a modelagem da documentacao.

Execute em ordem:

1. `01_tabelas_sqlserver.sql`
2. `02_views_sqlserver.sql`
3. `03_functions_sqlserver.sql`
4. `04_procedures_sqlserver.sql`
5. `05_indexes_sqlserver.sql`
6. `06_data_sqlserver.sql`

O primeiro script cria o banco `locadora` quando ele ainda nao existir. Os demais scripts assumem esse banco como contexto.
